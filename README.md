# Rhia Fe Arlan — Portfolio 🌸

A soft, pink-and-lavender personal portfolio (static HTML/CSS/JS, light & dark mode).

## Update your details
- **Profile photo:** add your picture as `assets/profile.jpg` (until then, the "RF" initials show).
- **Social links / email:** in `index.html`, replace every `href="#"` / `mailto:hello@example.com` marked with `data-todo`.

## Run locally
Open `index.html` in a browser — no build step needed.

## Deploy
Works as-is on GitHub Pages, Vercel or Netlify.
